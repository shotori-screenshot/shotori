## Custom toolbar actions

- Add user-defined custom toolbar actions configured via `[[custom_actions]]` in `settings.toml` or drop-in manifests under `~/.config/shotori/actions/`
- Define a standardized Unix I/O protocol with `file`, `stdin`, `ocr_text`, and `none` inputs, `SHOTORI_*` metadata environment variables, bounded stdout/stderr capture, timeout guards, and `copy_text`, `copy_image`, `pin`, `notify`, `json`, and `ignore` output handlers
- Support validated user `.svg` icons with mtime-based cache busting alongside 20 curated Lucide icon presets
- Wire parameterized `RunCustomAction` keybindings, a non-blocking top-center progress OSD, and Settings UI management with drag-and-drop toolbar editing

## Long capture

- Automatically disable window transparency and background blur during scroll capture via `[scroll] transparency_mode` (`auto` | `custom` | `off`, default `auto`), restoring compositor state immediately on exit via an RAII guard (#60)
- Built-in `auto` mode supports Hyprland, niri, and KDE KWin; `custom` mode runs user `enter_command` / `exit_command` hooks with `SHOTORI_SCROLL_*` environment variables (#60)

## Capture & clipboard

- Support 24-bit `BGR888` and `RGB888` `wl_shm` screencopy buffers (e.g. wlroots GLES2 drivers advertising `stride = width * 3`) across both regular capture and long capture, and skip unsupported offers within screencopy v3 format batches (#62)
- Handle `O_NONBLOCK` pipes asynchronously in the clipboard daemon so wlroots's Xwayland bridge no longer truncates large PNG pastes
- Add opt-in `[export] clipboard_file_uri` to offer `text/uri-list` alongside `image/png` so X11/Xwayland clients lacking `INCR` support can paste large screenshots (#58)

## Settings, QR & packaging

- Add locale-aware Website and Documentation links to the Settings About page and package metadata
- Quit the overlay cleanly when a QR scan fails (#54, #55)
- Add the optional `system-onnxruntime` Cargo feature to link a distro-provided `libonnxruntime` via `pkg-config` for musl/Alpine and system-library builds (#59)
