## Settings and direct save

- Direct save without dialog (`export.auto_save`, issue #42): Save and `Ctrl+S` write straight to a configurable default directory (`export.save_dir`, default `~/Pictures/Shotori`) with collision-free `-1`, `-2` suffixes across both selection and long-capture sessions
- Save & Export preferences (`[export]`): remember last dialog folder (`remember_last_dir`), filename templates (`filename_template` with `strftime` tokens plus `{w}` / `{h}` and live preview), default format (`png` / `jpeg` / `webp`), PNG compression level, JPEG quality and `copy_on_save`
- Capture & HUD preferences (`[capture]` and `[scroll]`): toolbar item visibility and drag reordering, smart region and window snapping toggles, crosshair, size badge mode (`logical` / `physical` / `bounds` / `hidden`), pixel loupe zoom and size, post-copy/post-save overlay persistence, reduced motion, default scroll axis and maximum sheet length
- Annotation, Notification, Pin, Shortcut and OCR preferences: custom 7-swatch toolbar palette and per-tool initial defaults (`[annotation]`), notification triggers, thumbnails and timeout (`[notify]`), floating pin border, shadow, edge snap and zoom modifier (`[pin]`), 25 configurable capture and annotation shortcuts (`[keys]`) with live tooltip chord hints, and multi-line space joining (`ocr.join_lines`) across all eight `shotori settings` pages

## Command-line interface

- `shotori gui`: pre-select `-f/--full`, `-s/--screen`, `-o/--output <NAME>`, `-r/--region <GEOM>` or `-w/--window`, delay capture with `-d/--delay`, and arm an initial annotation tool via `-t/--tool <TOOL>` (issue #36)
- `shotori full`: scope headless captures to full desktop, focused screen, named output, region or focused window, pipe PNG bytes with `--stdout` / `-p -`, and suppress notifications with `-n/--no-notify`
- `shotori ocr [IMAGE]` and `shotori pin [IMAGE]`: recognize text or float an always-on-top pin directly from a file, `-` stdin or live screen capture, with `--download` first-run model setup for OCR and `--output` / `--at <X,Y>` placement plus resident-owner socket handoff for pins
- `shotori outputs [--json]` and `shotori settings [PAGE]`: inspect connected Wayland outputs (`wl_output` + `zxdg_output_v1`) in human or JSON form, open settings directly to a named section, parse `x,y,w,h`, `x,y wxh` and `wxh+x+y` regions, and query focused window/output metadata across niri, sway and Hyprland

- Overhaul the live scroll-capture preview (issue #37): 1/256-pixel fixed-point area-box downscaling at physical output scale, natural left-to-right orientation for horizontal captures, adaptive side-panel sizing, a non-occluding status header, global scrollbar/minimap scrubbing with automatic live-follow resume, and Pin (`Ctrl+P` / toolbar button) as a direct scroll-capture exit

- Replace the fixed 3-minute wall-clock cutoff with an inactivity deadline, scale maximum sheet height with output capture scale, hold at `Max length` for confirmation instead of silently truncating, and apply preview queue backpressure without dropping terminal session events
