## QR code scanner

- Add QR code scanning as a capture exit and CLI subcommand (`shotori qr [IMAGE]`, issue #46, PR #47): decode QR codes directly from a selection, file, `-` stdin or live screen capture, copy the decoded payload to the clipboard, and configure the action shortcut and toolbar item in settings

## Release packaging

- Fix the AUR release job in CI to run a full `pacman -Syu` upgrade before installing `git` and `openssh`, avoiding partial-upgrade dependency conflicts when the `archlinux:base-devel` container lags behind the repositories (also carries all changes from [v0.18.0](https://github.com/shotori-screenshot/shotori/releases/tag/v0.18.0))
